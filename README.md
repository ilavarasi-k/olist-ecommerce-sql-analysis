# Olist E-commerce Store Analysis using SQL

## Project Overview
This project analyzes Brazilian e-commerce data using Oracle SQL Developer to understand order trends, customer distribution, product sales, and payment patterns.

## Tools Used
- Oracle SQL Developer
- SQL
- GitHub

## Key Analysis
- Order Status Analysis
- Customer State Analysis
- Top 10 Orders by Value
- Monthly Sales Analysis
- Product Category Sales Analysis
- Payment Type Analysis
- Payment Installment Analysis
- Customer Order Analysis
- Order Item Price Analysis
- Shipping Cost Analysis
- Average Order Value Analysis

## SQL Skills Demonstrated
- SELECT and filtering
- GROUP BY and ORDER BY
- Aggregate Functions
- JOIN
- Subqueries
- Date Formatting
- ROWNUM

## Project Objective
To explore e-commerce data and identify useful business trends through SQL queries.
